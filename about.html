About us

This page is a snapshot of affordable premium and ultra cruise fares collected from Bulgarian travel agencies and from the cruise lines’ own sites. It is not a booking engine: each row links out to the page that published that fare.

Interior cabins and ordinary ocean-view staterooms are already excluded. What remains is a balcony cabin or better, an all-inclusive bundle on that same standard, or a luxury / ship-within-a-ship product.

A departure can appear more than once. The same sailing is listed once per website that sells it, and once per rate tier it still qualifies under. Line, Source, Ship, and Rate each accept more than one value; Rate cards on the sailings page toggle rate tiers the same way. The list opens Ultra first, then All included, then Economy, cheapest per night within each rate. Click a column header to sort differently. The address bar updates as you filter and sort, so you can copy the link and send someone the same view.

Prices stay in the currency that website published. Nothing is converted, so a dollar figure is not comparable to a euro one. Per night is the fare divided by the nights the sailing spans — not the marketed day count.
